§ 1 · Learn

The Pumping Lemma, in plain language

Every regular language is recognised by a machine with finitely many states. Feed it a long enough string and it must revisit a state — so part of the string sits on a loop that can be repeated, or skipped, without the machine noticing.

Formal statement

∀ regular L ∃ p ≥ 1 :
∀ s ∈ L with |s| ≥ p,
∃ x, y, z with s = xyz such that
  (1) |y| > 0
  (2) |xy| ≤ p
  (3) xyⁱz ∈ L for every i ≥ 0

What it says

If a language is regular, there is a number p (the pumping length) with this property: any string in the language that is at least p symbols long can be cut into three pieces x, y, z.

The middle piece y is not empty, it starts within the first p symbols, and you can repeat it as often as you like — or delete it — and the result is still in the language.

How it is used: to show a language is not regular, find one long string where every allowed cut breaks when pumped. The lemma can never prove that a language is regular.

1

y is not empty

|y| > 0

The loop must consume at least one symbol. Pumping an empty y would change nothing, so the condition would be trivially true.

2

x and y fit in the first p

|xy| ≤ p

A machine with p states repeats a state within its first p moves, so the loop is found early. This pins y to the start of the string.

3

Pumping stays inside L

xyⁱz ∈ L, ∀ i ≥ 0

Going round the loop zero, one, two or more times lands in the same state, so every pumped string must be accepted too.
